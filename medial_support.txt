1. Title for application
V Player - Modern Media Player for Windows

2. Short description
V Player is a fast, beautiful media player for Windows powered by mpv. It plays virtually any video, audio, and image format with hardware-accelerated decoding, a smart playlist, and a glassmorphism dark/light UI.

3. Long description
V Player is a modern media player built for Windows, powered by the legendary mpv engine for maximum format support and smooth hardware-accelerated playback. It plays over 70 media formats - including MP4, MKV, AVI, MOV, WebM, FLAC, and more - in video, audio, and image.

The player is designed around a clean glassmorphism interface with light and dark themes, a fully customizable accent color, an auto-hiding control bar, a smart playlist with drag-and-drop reordering, and subtitle track selection. Enjoy keyboard shortcuts for everything, frame-by-frame stepping, playback speed control, and auto-advance through your playlist. V Player is built with Tauri v2 and React for a tiny footprint and native-level performance.
