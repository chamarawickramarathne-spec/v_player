1. TITLE
V Player

2. SHORT DESCRIPTION
A fast, modern Windows media player powered by mpv — video, audio, and images in one sleek app.

3. LONG DESCRIPTION
V Player is a lightweight desktop media player for Windows built with Tauri and the industry-proven mpv engine. Play virtually any video, audio, or image format with hardware decoding, a clean dark UI, playlist management, drag-and-drop, keyboard shortcuts, and one-click updates from GitHub. Designed for speed and low overhead: capped demuxer cache, efficient UI updates, and a focused feature set without bloat.
