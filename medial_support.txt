1. Title
V Player

2. Short description
Modern Windows media player powered by mpv — play almost any video, audio, or image with a clean recent library, real video thumbnails, and resume.

3. Long description
V Player is a fast, modern media player for Windows built with Tauri and the mpv engine. Open local files or network streams, build playlists with reliable next/previous and auto-advance, resume where you left off, and browse recent media with real video thumbnails generated automatically. Supports a wide range of video, audio, and image formats, hardware decoding, subtitles, loop/shuffle/A-B, and one-click updates from GitHub Releases.
