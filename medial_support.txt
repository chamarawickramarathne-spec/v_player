1. TITLE
V Player

2. SHORT DESCRIPTION
Modern Windows media player with resume, playlists, streams, and mpv-powered playback.

3. LONG DESCRIPTION
V Player is a fast desktop media player for Windows built on Tauri and mpv. Play local video, audio, and images; open network URLs and streams; manage playlists with shuffle and repeat; set A-B loops; switch audio and subtitle tracks; resume where you left off from Recent Media. One-click updates from GitHub keep you current.
